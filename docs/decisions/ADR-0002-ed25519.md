# ADR-0002: Ed25519 signatures

- Status: Accepted
- Date: 2026-08-12

## Context

Receipts and release manifests require compact, deterministic public-key signatures with
widely reviewed implementations.

## Decision

Use Ed25519 through the `cryptography` library. Runtime verifier modules accept public keys
only. Key generation and signing remain separate commands and private keys are never stored in
the repository.

## Consequences

Signature verification is simple and interoperable. Security still depends on key custody,
identity binding, dependency integrity, and canonical message construction.
