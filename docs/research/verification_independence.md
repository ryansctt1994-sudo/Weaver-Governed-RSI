# Verification independence

Independence is a property that requires evidence, not a checkbox supplied by the producer.

At minimum, an independent replication receipt should disclose:

- operator and organization identity;
- relationship to producer and funder;
- architecture, operating system, runtime, and dependency lock;
- source and bundle digests;
- commands executed and raw exit states;
- instrument errors and deviations;
- generated replicator public key and receipt signature.

Heterogeneity should be meaningful for the claim. A different cloud region with the same
image may not test supply-chain assumptions; a different CPU architecture and clean dependency
resolution may.
